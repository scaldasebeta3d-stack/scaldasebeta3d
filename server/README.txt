BACKEND DE ARRANQUE

Este servidor é apenas uma base técnica para a versão online.
Para produção deve ser acrescentado:
- autenticação segura de administrador;
- base de dados persistente;
- validação de dados;
- proteção de sessão/tokens;
- backups;
- HTTPS;
- integração com faturação.

O GitHub Pages serve a parte pública, mas não executa este servidor Node.
